# koru/signal — what is Koru vs what is the emit weld

## Koru (koruc host programs)

Runnable reference: **`examples/breath_demo.k`**

```bash
cd ~/src/koru-libs/signal/examples
KORU_HOME=~/src/koru koruc breath_demo.k
./a.out
# PASS: breath demo — alarm=1, dip_ticks=18
```

Host syntax pinned by the signal suite:

| Spelling | Role | Pinned by |
|----------|------|-----------|
| `koru/signal:shape(Name) { name[unit] … }` | norun port metadata | `tests/shape_surface`, `breath_demo.k` |
| `const { name: value … }` | design constants in host `.k` | `breath_demo.k` |
| `koru/signal:init(Name)` | compile boundary + register | `breath_demo.k`, suite |
| `koru/signal:tick(Name, pass_rate: r)` | external-clock step | `tests/external_tick`, `breath_demo.k` |
| `koru/signal(Name)` | bare reference | suite |

Bind-first: `tor(args): binding |> …` — no calls inside argument positions (**KORU104**).

**Not Koru host syntax:** `block { … }`, `:init(Name) { peak: 0 … }` seed bodies — those tokens appear only in the emit-weld input file below; `koruc` does not compile them today.

## Emit weld (maintainer path → `models/*.zig`)

Pre-built models (`models/breath.zig`, `models/floor.zig`) are what host programs link. They are regenerated by:

```bash
cd ~/src/koru-libs/signal/codegen && bash run.sh
```

Maintainer input text: **`models/breath.koru.kz`** — Koru-*shaped* text scraped by `codegen/model_emit.zig` (`findBlock`, brace matching) and lowered to EEL → Zig. **Not fed to koruc.** Verified by oracle parity in `run.sh`, not by the regression board.
